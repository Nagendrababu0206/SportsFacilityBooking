# SportsFacilityBooking

A visually stunning, modern, and highly interactive Full-Stack Sports Facility Booking System. 

## Features
- **Instant Slots Reservations**: Real-time slot availability checking and reservation.
- **Vibrant, Interactive UI**: Beautiful glassmorphism, smooth animations, customized gradients, and modern typography (Vanilla CSS).
- **Own Your Game Dashboard**: Manage upcoming games, booking history, and view personalized user stats.
- **Stunning Court Graphics**: Engaging illustrations and graphics highlighting each court type.
- **Robust Backend**: Node.js & Express REST API powered by MongoDB for secure, consistent slot scheduling and booking management.
